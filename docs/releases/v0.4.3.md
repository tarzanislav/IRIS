## IRIS 0.4.3 – server učebne celý z konzoly

**Učenie v učebni**
- **Nová stránka Server v konzole:** stav servera (verzia, ako dlho beží, čas servera oproti konzole, model učebne a
  jeho plán, voľné miesto, pamäť, písma na meranie čítačky), **Aktualizovať server teraz** s výsledkom poslednej
  aktualizácie, **Reštartovať server…** a **denník servera aj aktualizácie** s hľadaním.
- **Model z vydania…:** učebňa začne od podpísaného učiaceho súboru najnovšieho vydania – server ho stiahne, overí
  podpis a SHA‑256, doterajší model odloží vedľa a sám sa reštartuje. Na serveri netreba nič písať.
- Server si vedie **vlastný denník** (`/var/lib/iris-hub/logs/`, najviac 2 × 2 MB): pripojenia počítačov a konzol,
  kolá, testy čítačky, zmeny z konzoly, chyby. Nič ďalšie netreba inštalovať.
- **Oprava:** po aktualizácii sa server znova sám reštartuje (v 0.4.1 a 0.4.2 sa nový program nahral, ale bežal
  starý). Pri prechode z 0.4.2 na 0.4.3 treba ešte raz `systemctl restart iris-hub`, potom už nie.
- `iris-ocr-train.iris` je teraz aj v podpísanom zozname programov učebne.

**Vlastné OCR:** model ako v 0.4.1 (CER 1,77 % známe písma, 1,02 % neznáme písmo).

**Súbory:** ako v 0.4.2.
