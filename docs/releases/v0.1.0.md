## IRIS 0.1.0 – prvé vydanie (F1 + F2)

Vlastný strojový prekladač **EN→SK** v C# (.NET 10), bez cudzích knižníc za behu. Beží v počítači, nič neposiela.

**Súbory**
- `Iris.Core.dll` – knižnica jadra (pre UNIVERSUM a iné programy, .NET 10)
- `iris-0.1.0-win-x64.zip` – príkaz `iris.exe` pre Windows (nič neinštaluje, .NET je v ňom): preklad, meranie rýchlosti a kvality
- `opus-mt-en-sk-int8.iris` – model EN→SK v int8 (79 MB), váhy OPUS-MT (Apache-2.0)
- `LICENSE`, `NOTICE.txt` (pôvod a licencie), `SHA256SUMS.txt`

**Čo vie**
- **Preklad zhodný s referenciou:** float32 jadro dáva na 500 vetách presne rovnaké tokeny ako Hugging Face transformers (greedy aj lúč).
- **Rýchlosť:** nadpis a úvod článku za **0,4 s** (greedy) / **0,9 s** (lúč) na 2-jadrovom procesore, model int8.
- **Kvalita:** chrF2 na FLORES-200 devtest en→sk **58,1** (int8), float32 58,2.
- **Delenie textu na vety** so zachovaním rozloženia, **pamäť prekladov** (opravy vlastníka) a **slovník mien a názvov**.

**Príkazy** (`iris.exe` v priečinku so súborom modelu)
```
iris translate opus-mt-en-sk-int8.iris "The premiere is tonight."
iris bench opus-mt-en-sk-int8.iris
iris translate opus-mt-en-sk-int8.iris --memory pamat.jsonl --glossary nazvy.tsv < clanok.txt
```
